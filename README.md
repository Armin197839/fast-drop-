# FastDrop ⚡ — انتقال سریع و مستقیم فایل در شبکه محلی (WiFi / LAN)

برنامه **FastDrop** یک راهکار بومی، پایدار و پرسرعت برای انتقال مستقیم و بدون واسطه انواع فایل بین دستگاه‌های موجود در یک شبکه محلی (Wi-Fi یا Hotspot) است.

این برنامه بدون نیاز به اینترنت، مصرف حجم دیتا یا استفاده از سرورهای ابری، انتقال بایت‌به‌بایت فایل‌ها را با بالاترین پهنای باند ممکن در شبکه محلی فراهم می‌سازد.

---

## 🚀 ویژگی‌های کلیدی

- **انتقال مستقیم دستگاه به دستگاه (P2P via Local HTTP):** بدون واسطه و بدون آپلود ابری.
- **سرور HTTP یکپارچه و بهینه:** استفاده از سوکت‌های بافرشده (Buffer 64KB) در فرستنده، بدون ذخیره‌سازی کل فایل در حافظه موقت (Zero Full-RAM Buffering).
- **تولید کد QR آفلاین:** تولید لحظه‌ای و آفلاین کد QR شامل آدرس مستقیم دانلود توسط کتابخانه ZXing.
- **دانلود جریانی با OkHttp:** دانلود تکه‌به‌تکه با محاسبه واقعی درصد پیشرفت و سرعت بر حسب مگابایت بر ثانیه (MB/s).
- **امنیت فایل و جلوگیری از تداخل:** ذخیره‌سازی اولیه در فایل موقت `.part`، پاک‌سازی در صورت لغو یا قطعی شبکه، و نام‌گذاری هوشمند در صورت تداخل نام فایل‌ها (`file (1).ext`).
- **رابط کاربری راست‌چین (RTL) و فارسی:** طراحی مدرن بر پایه متریال دیزاین ۳ با پالت رنگی حرفه‌ای (آبی الکتریک و سبز نعنایی).
- **صفحه فرود تحت وب:** امکان دانلود فایل حتی با مرورگر کامپیوتر یا گوشی‌های دیگر بدون نیاز به نصب برنامه.

## 🛠 معماری نرم‌افزار

معماری FastDrop بر پایه MVVM و تفکیک وظایف پیاده‌سازی شده است:

```text
                     ┌────────────────────────┐
                     │     MainActivity       │
                     └───────────┬────────────┘
                                 │
                     ┌───────────▼────────────┐
                     │   FastDropViewModel    │
                     └─────┬────────────┬─────┘
                           │            │
         ┌─────────────────▼──┐      ┌──▼────────────────┐
         │   FastDropServer   │      │FastDropDownloader │
         │  (Embedded HTTP)   │      │ (OkHttp Streaming)│
         └─────────────────┬──┘      └──┬────────────────┘
                           │            │
                     ┌─────▼────────────▼─────┐
                     │ Network / File System  │
                     └────────────────────────┘
```

## 📱 نیازمندی‌ها و دسترسی‌ها

- **Android SDK:** حداقل API 24 (Android 7.0) تا Android 14+ (API 36).
- **مجوزهای شبکه:**
  - `android.permission.INTERNET`
  - `android.permission.ACCESS_NETWORK_STATE`
  - `android.permission.ACCESS_WIFI_STATE`
  - `android.permission.CHANGE_WIFI_STATE`
  - `android:usesCleartextTraffic="true"` (جهت انتقال در شبکه محلی روی پورت HTTP)
- **مجوز FileProvider:** جهت باز کردن ایمن فایل‌های دانلود شده.

## 📖 راهنمای استفاده

1. **اتصال به شبکه:** مطمئن شوید هر دو دستگاه فرستنده و گیرنده به یک مودم Wi-Fi یکسان یا هات‌اسپات متصل هستند.
2. **ارسال فایل:**
   - در دستگاه فرستنده وارد بخش «ارسال فایل» شوید.
   - فایل مورد نظر خود را انتخاب کرده و «شروع اشتراک‌گذاری» را لمس کنید.
   - کد QR و آدرس دانلود نمایان می‌شود.
3. **دریافت فایل:**
   - در دستگاه گیرنده وارد بخش «دریافت فایل» شوید و آدرس را وارد کرده یا کد QR را اسکن کنید.
   - پیشرفت دریافت، سرعت زنده و حجم فایل به صورت لحظه‌ای نمایش داده می‌شود.
   - پس از پایان دانلود، با دکمه «باز کردن فایل» به فایل دسترسی پیدا کنید.

## 🔒 ملاحظات امنیتی

- نرم‌افزار FastDrop برای انتقال سریع در محیط شبکه خانگی یا اداری امن (LAN) طراحی شده است.
- ترافیک در شبکه محلی به صورت مستقیم بین فرستنده و گیرنده مبادله می‌شود و به سرورهای خارجی ارسال نمی‌گردد.
- کلیه اسامی فایل‌ها قبل از ذخیره‌سازی پالایش شده و در برابر خطرات Path Traversal محافظت می‌شوند.
